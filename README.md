# INKAA Workspace

Production-ready futuristic CRM SaaS scaffold built with Next.js 14, TypeScript, Tailwind, Prisma, Supabase-ready architecture, OpenAI and Stripe API routes.

## Setup

```bash
npm install
cp .env.example .env.local
npm run db:generate
npm run dev
```

## Features
- Premium CRM dashboard with floating sidebar, metric cards, customer workspace, timeline/messaging/deal/task panels.
- Auth screens, onboarding, analytics module.
- API routes: AI summaries, Stripe checkout, leads endpoint.
- Prisma schema for users and leads.
- Dark-mode ready tokenized color system.
